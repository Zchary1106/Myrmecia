# Hashtag Planning

## Rules
- 标签 = 大流量词 + 精准长尾词：大流量词带来曝光，长尾词带来转化与搜索命中。
- 每个标签必须是真实可搜的词或短语，不编造话题。
- 与正文关键词自然对应，避免堆砌无关标签。
- 有 `content.hashtag_plan` 工具时优先调用/参考其组合结果。
- 小红书 10-15 个；抖音 5-10 个；公众号 5-8 个（按平台习惯）。

## Output
- 标签清单（分平台，标注用途：流量/长尾）
- 关键词清单（供 SEO 与正文植入）
- 与标题、正文、封面的对应关系说明
