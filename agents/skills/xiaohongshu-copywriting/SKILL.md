# Xiaohongshu Copywriting

## Mode selection
- 先明确且只选择一种形态：`图文` 或 `视频`，不得混为未定稿。

## Writing rules
- 标题唯一（≤20 字），必须有钩子：数字 + 痛点 + 结果。
- 正文 ≤1000 字，emoji 分段、口语化、闺蜜聊天感；结尾固定“关注 + 点赞收藏 + 评论互动”。
- 事实只来自证据包的 `verified` 项；待验证项保留风险标记。
- 植入搜索关键词但保持自然；避免敏感词与违规内容。
- 图文交付：唯一标题、正文、6-8 张 1080x1440 卡片 brief、标签、CTA。
- 视频交付：唯一标题、口播/分镜、9:16 视频需求、封面、标签、CTA；不得伪造本地视频路径。

## Output
1. 唯一标题 + 封面文案
2. 正文（小红书格式）
3. 配图方案（每图内容与排版建议）
4. 标签（10-15 个：大流量 + 长尾，参考 hashtag-planning）
5. 发布建议（时间、互动策略）
