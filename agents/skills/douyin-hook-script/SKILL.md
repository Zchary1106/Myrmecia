# Douyin Hook Script

## Hook constraints
- 前 3 秒必须抓人：疑问句 / 反常识断言 / 结论前置再倒叙。
- 每个镜头/beat 3-8 秒，单镜头不超过 15 秒。
- 杜绝废话开场（“大家好今天给大家分享…”）。

## Structure templates
- 知识科普：反常识开场 → 是什么 → 为什么重要 → 怎么用/验证 → 一句话总结 + 互动
- 好物清单：痛点场景 → 逐个亮点（含画面）→ 推荐位 → 互动
- 方法教程：结果前置 → 编号步骤 → 常见误区 → 互动

## Rules
- 唯一标题、唯一事实来源（content core 的 `verified` 项）；待验证项不得写成结论。
- 9:16 竖屏（1080x1920）；标出需人工提供的本地视频路径，不生成、不猜测路径。
- 信息密度高，避免 AI 套话（“首先其次最后”“众所周知”）。
- 结尾必须有明确互动引导；避免导流私域、涉政与医疗诊断类断言。

## Output
- 标题、时长建议（15 秒-3 分钟）
- 分镜表（镜头/时间轴/画面/口播/字幕）、0-3 秒 Hook 说明
- 完整口播稿、封面文案、发布配文 + 5-10 个标签
