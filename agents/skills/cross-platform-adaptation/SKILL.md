# Cross-Platform Adaptation

## Rules
- 所有平台共享核心观点与事实清单；只允许平台层差异（标题、结构、CTA、媒体形态）。
- 抖音：9:16 视频优先，前 3 秒 Hook，分镜/口播/字幕。
- 小红书：3:4 图文（≤1000 字，6-8 张卡片）或 9:16 视频；先明确唯一形态。
- 公众号：长图文 HTML，深度与来源可追溯。
- 事实不得跨平台漂移；某平台证据不足时明确标注，不补造。
- 每条平台终稿必须唯一确定，不保留多备选。

## Output
- 每个平台的最终稿清单（标题/正文或脚本/媒体规格/标签 CTA）
- 平台差异点说明
- 待验证或待人工确认事项列表
