# Shot List Design

## Rules
- 每行记录：序号、时长、画面内容、口播文案、字幕（画面文字）。
- 每个 beat 3-8 秒；复杂概念拆成“是什么→为什么→怎么用”。
- B-roll 清单只列可获取或人工提供的素材；不虚构路径、版权或授权。
- 需要真实视频文件的项必须标注“待人工提供本地绝对路径”。
- 9:16 竖屏优先（1080x1920）；横版必须标注为例外并要求人工确认。

## Output
- 分镜表（镜头/时间轴）
- B-roll / 素材清单（来源与缺失标注）
- 字幕节奏与封面文案建议
